# 📝 TaskCollab

**TaskCollab** es una aplicación web orientada a la organización de actividades, pensada tanto para uso personal como colaborativo. Permite gestionar tareas de forma intuitiva, con una interfaz limpia y moderna.

---

## 🚧 Dificultad: 💀 Difícil

---

## 🎯 Historias de Usuario

> Estas historias representan los requerimientos del sistema desde el punto de vista del usuario final.

### Funcionalidades implementadas en la primera etapa

- ✅ Como usuario, quiero **crear nuevas tareas** para organizar mis actividades pendientes.
- ✅ Como usuario, quiero **marcar tareas como completadas** para dar seguimiento a mi progreso.
- ✅ Como usuario, quiero **eliminar tareas** para mantener mi lista organizada.

### Funcionalidades planeadas para futuras versiones

- ✏️ Como usuario, quiero **editar tareas existentes** para corregir o actualizar información.
- 👥 Como usuario, quiero **asignar tareas a miembros de mi equipo** para trabajar de forma colaborativa. *(Requiere replanteo y análisis de roles de usuario)*
- 🎨 Como usuario, quiero **asignar colores o etiquetas** a las tareas para identificar su prioridad.
- 💾 Como usuario, quiero que **la información sea persistente** aunque cierre el navegador.
- 📋 Como usuario, quiero **agregar una descripción detallada** a cada tarea para organizar los pasos a seguir.
- 🖼️ Como usuario, quiero **adjuntar imágenes a las tareas** para una representación visual más clara.

---

## 🛠️ Implementación actual

### Funcionalidades desarrolladas

- ✅ Interfaz responsive mediante **CSS**.
- ✅ Estructura **HTML semántica**.
- ✅ Lógica en **JavaScript puro**.
- ✅ Añadir tareas dinámicamente.
- ✅ Marcar tareas como completadas.
- ✅ Eliminar tareas.
- ✅ Visualización de estadísticas:
  - Total de tareas.
  - Tareas completadas.
  - Tareas pendientes.
- ✅ Persistencia local de los datos utilizando **localStorage**.

---

## ⛔ Limitaciones actuales

- ❌ No existe autenticación ni registro de usuarios.
- ❌ No hay colaboración real entre usuarios (solo modo local).
- ❌ No se pueden editar tareas ni agregar descripciones o imágenes aún.
- ❌ Sin conexión a base de datos ni backend implementado.

---

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3 + Bootstrap 5
- JavaScript Vanilla
- FontAwesome para íconos
- localStorage para persistencia

---

## 📌 Notas del equipo

Este proyecto está en evolución constante y se encuentra en una etapa inicial. El objetivo es iterar sobre este MVP (Producto Mínimo Viable) incorporando funcionalidades avanzadas como edición, colaboración en tiempo real y persistencia con base de datos.
